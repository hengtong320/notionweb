# V50 姿势体表关系修正

入口：[生活姿势](pose.html?v=50.0.0) · [解剖与经穴](index.html?v=50.0.0)

保留 120 种姿态，以及男女体表、经穴、骨架、器官、神经和血管观察。颈、胸、腰分节附加弯曲与定位功能继承 V49。

本轮修正六种左右侧卧的腕部目标与肘部方向参照，让上、下侧手臂离开胸廓；修正下犬式、宽膝婴儿式的上臂旋转参照；前屈姿态的手臂适度分开。婴儿式的膝部间距和屈膝设置减少体表穿插，仍有残留。

体表保持不透明；每个性别使用自己的皮肤三角附着，线路、点和名称沿同一姿态更新。没有移动穴位来隐藏穿插，也没有改动源皮肤或骨块形状。

完整诊断和剩余问题见 [本轮复核](../atlas50-tools/REVIEW.md)。真实组织压力、神经张力、椎间盘压缩和病变预测仍未求解；穴位医学定位仍需逐点校准。
