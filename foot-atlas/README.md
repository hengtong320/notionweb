# 足骨研习室 — 完整模型版

## 直接访问

**https://hengtong320.github.io/notionweb/foot-atlas/**

电脑浏览器打开上述网址，不要把 GitHub 源码页面当作运行页面。

此目录的 `index.html` 是完整的独立网页：Three.js 渲染代码及足骨网格均内置。网页本身加载后，不需要访问外部模型源、CDN，也不需要登录或导入 OBJ。

此前聊天中名为 `foot-atlas.html`、大小约 95 KB 的旧附件不是这个完整版本；该旧附件没有内置模型，外部下载失败时会出现空白或缺少骨骼。请以本目录的完整版本为准。

## 操作

- 整体观察：拖动旋转，滚轮缩放，右键拖动平移。
- 识骨：单击模型或左侧骨名，右侧显示中文名、难字读音和说明。
- 拆解：切到移动模式，按住骨块拖出；旋转模式可单独转动一块骨。
- 关节关系：单独查看、相邻骨强调、原位参考、整体展开滑杆。
- 恢复：点击归位或恢复整足。自由拆解不代表人体真实关节活动范围。

## 版本与边界

本版本显示 28 个独立骨块（26 块主要足骨及 2 块籽骨），源网格共 16,586 个三角面。使用有来源的 Z-Anatomy / BodyParts3D 派生表面模型，不是球体或圆柱拼接，也不是患者 CT 或临床精度模型。没有模拟软骨、韧带、内部骨小梁或正骨手法。

`MODEL-LICENSES.txt`、`assets/provenance.json` 保留数据来源、处理记录和许可；网页代码与模型遵循各自许可。

## 测试证据

- `qa/report.json`：完整模型的浏览器交互回归。
- `qa/delivery-report.json`：公开网址实际访问、与仓库构建校验、阻断外网后的离线加载、逐骨点选、实际拖拽、归位和浏览器兼容性验证。以报告中的 `success`、时间与各项结果为准。
- `qa/*-overview.png`、`qa/*-single-bone.png`、`qa/*-exploded.png`：相应浏览器实测截图，不是效果图。

`.github/workflows/foot-atlas-delivery-check.yml` 在发布说明或验证脚本更新时重新运行上述检查。检测通过不等于已覆盖所有电脑、显卡或浏览器。

若网页显示“硬件加速”提示，说明该环境未能创建 WebGL 上下文；请在独立的 Chrome、Edge 或 Safari 浏览器打开，而不是只在聊天附件预览中查看。
