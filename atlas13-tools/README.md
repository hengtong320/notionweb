# V13 视角保持与经脉分辨

保留 V12.0.1 的界面风格和原解剖模型。经脉筛选、左右切换和点击线路不再自动调用看全线；主动点穴位仍可聚焦，主动点看全线才全段导航。

男女性共用结构目录、经络穴位、结构图层标签及快捷观察场景。女性切换预先加载对应源结构，按整体坐标框架保持相对观察方向与放大程度，不重置为正面全身。不同来源模型的身体比例和局部形态不同，本次不是非刚性解剖配准。女性骨骼、肌肉覆盖仍不全，不拿男性网格或经穴补齐；女性经穴目录可查资料，未显示男性坐标。

上肢六经的区域导览分别保留掌侧桡侧/中部/尺侧与背侧分区；原参照记录保留，修订坐标带 navigationRevision:13 和 navigationOnly 标记。贴面采用分部位、分左右的方向投影，不再跨全身寻找最近三角形。心经与心包经在前臂不再因投影挤到同一边界。图形比较测试不等于逐穴医学定位审核，所有穴位依然不是准确取穴坐标。

长强 GV1 标准拼音为 cháng qiáng。本次对长强、大椎、龈交、郄门、阴郄、膻中生成专项消歧合成音频，显示名称与语音提示分离。没有声称全套音频人工审听完成。
