# V40 · 120种生活姿势与身体负担

入口：`pose.html`。解剖页的“120种生活姿势”入口可直接进入；男女、经络、经穴、器官与神经的原有解剖查看保留。

120项实质不同的生活动作和支撑条件：卧躺16、坐姿16、站立12、搬抬12、家务12、出行运动12、工作12、休闲8、瑜伽12、游泳8。包括左右侧卧、夹枕、蜷腿、仰卧屈膝、小腿放凳、俯卧、半卧，以及不同的站坐与负重距离。

同一男性参考骨架的210骨块按近似关节中心摆位。四肢保持源链长度，五节腰椎和七节颈椎逐级旋转；可达约束和参考地面支撑由模型检查。图册使用实际骨架绘制，各场景附支撑示意物。行走、跑步支撑阶段和自由泳阶段支持阶段内播放，其他运动提供独立动作状态。它们不是测量过的完整运动轨迹。

先读动作说明和身体负担，再调整时间、负重、重力和水中排水体积。相同负重贴身与伸远的比较显示物体对近似腰部参照点的外力矩 `m×g×水平距离`。持续时间只展示活动/保持时长与计划换姿次数，不制造疲劳百分比或损伤概率。水中只计算设定体积的浮力，不求水阻和推进力。依据链接随场景展示。

观察记录包含所选姿态、实际求解关节中心、输入条件、分析和限制；可预览、复制、下载JSON。参数保存在当前链接片段中，可重开复现。桌面与手机均支持缩放、完整显示、观察方向及旋转/平移模式。

限制：成人男性参考骨架，关节中心、动作范围和软组织未个体校准。没有肌肉/韧带/平衡、内部关节力、椎间盘压力或损伤预测。女性姿势配准、器官变形、神经牵拉和经穴随动未实现。骨块参考接触位置不等同真实人体接触压力。

本地：在仓库根目录启动静态服务器，打开 `/fullbody-tcm-v38/pose.html`。重建固定依赖 three 0.180.0、three-mesh-bvh 0.9.2、esbuild 0.25.10；设置 NODE_PATH 后运行 `node atlas38-tools/build.cjs`。旧版和原始模型资源保留。模型衍生遵循 CC BY-SA 4.0；保留 Z-Anatomy / BodyParts3D 来源。
