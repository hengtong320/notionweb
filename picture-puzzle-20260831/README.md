# 拼图合合 H5

一个可直接在手机或桌面浏览器运行的单文件 H5 拼图消除游戏。

## 在线体验

GitHub Pages：`https://hengtong320.github.io/notionweb/picture-puzzle-20260831/`

## 操作

- 拖动一个碎片或已经拼接的组合块，与目标区域交换。
- 同一图片的碎片在正确相对位置相邻时会自动连成整体。
- 四个象限组成完整 2×2 图片后会放大、消除、下落并补牌。
- 支持提示、撤销、整理、选关、图鉴和本机进度保存。

## 内容

- 36 幅内嵌原创矢量图片
- 24 个关卡
- 4×4 棋盘与四列牌堆
- 组合块刚体移动、连锁消除、翻牌补牌和结算动效
- 无外部依赖，支持离线运行

> 玩法根据用户提供的录屏重新实现；名称、界面和图片素材均为原创版本。
