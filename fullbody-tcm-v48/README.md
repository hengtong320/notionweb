# V48 人体研习室

index.html 为解剖与经穴；pose.html 为 120 种生活姿势。本地静态服务从仓库根目录启动，模型引用保留的 V9/V11/V12 资源。

姿势页上方选择人体与图层。皮肤/经络/穴位、内脏、神经和动静脉可在当前姿势切换；腰椎、颈肩、髋膝的局部聚焦保留当前图层。男女共用神经复用已加载模型，女性原生结构分别保留。

打开“脊柱分节与弯曲示意”，选择 C1–C7、T1–T12、L1–L5，可定位真实骨块，并叠加颈段/腰段前后屈与侧屈，再切换图层观察。同一姿势的零附加调整作为位置与方向对照；记录保存逐节数据和参数。胸椎尚未独立弯曲，教学参数不是 Cobb 角或活动范围。

本轮修正三个双手手机场景的接触与皮肤权重，点选、经穴三角附着与 GPU 使用同一混合；源骨块不缩放。其他姿势保留 V47 绑定。穴名会考虑皮肤与不透明手持物遮挡。

掌部拉伸、男性源皮肤缺口和部分身体穿插仍存在。几何随动不是组织力学求解；没有个人器官压力、神经张力、内部关节力或病变预测。保持时间用于研究任务暴露与换姿计划，不自动判断某节受损。

验证与继续工作的清单见 atlas48-tools/REVIEW.md；整个研究目标未标为完成。
