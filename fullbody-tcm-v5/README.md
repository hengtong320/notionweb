# V5 分层观察 · 网页版

入口：https://hengtong320.github.io/notionweb/fullbody-tcm-v5/

从聊天交付的 V5 源码还原，保留原210个骨块。肌肉、神经和音频为同站点按需加载，无需下载HTML或手动部署。旧版本不覆盖。

督脉走向导览独立于已标注穴位，显示为虚线；支持多经脉对照，收起控制区不隐藏图层。骨骼结构、肌肉外形、神经走行、分层对照四个预设；操作栏可折叠，鼠标指向缩放。

经络路径与95个有手工参照标记的穴名均未完成临床定位校准；虚线顶点不是新增穴位。不用于准确取穴、针刺、诊断或复位。不存在完整皮肤与皮下脂肪层。模型显示预设中的透明、透视是学习效果，不代表实际组织透明度或真实遮挡。

已知易错读音启用提示与普通话回退，但没有重新生成并逐条审听全部音频。浏览器测试检查加载、渲染及交互，不是解剖定位准确度或专业读音认证。

发布结果与具体浏览器检查以 delivery-release.json 和 checks/ 内记录为准。模型许可与署名见 MODEL-LICENSES.txt。
