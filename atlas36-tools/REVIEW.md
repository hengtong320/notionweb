# V36 体验复核：局部观察与控制

本轮针对“难以控制、不能方便放大局部、控制器难找”进行复现、修复和实际浏览器操作。保留 V35.0.1 所有体表和资料修复，独立发布 V36，旧版可回退。

## 按操作流程检查

1. 找到观察控制 — 已修复。原入口是小图标，平移藏在展开模式。现在底部明确显示旋转、平移、选位置、缩小、放大、看当前、完整显示、回全身。首次无参数打开会按最终界面空间重新取景，解决人物过小。证据：17-initial-bones-final.png。
2. 放大任意身体位置 — 已验证。点“选位置”再点实际皮肤，或双击可见结构，保持方向并改观察中心。点空白会提示，不误选其他结构。局部观察提示说明原穴位资料仍保留。证据：13-picked-arm.png。
3. 缩放、平移、旋转 — 鼠标点击/拖动已验证。放大倍率 0.8、缩小倍率 1.25，可返回相同距离；平移保持观察方向，旋转保持中心。缩放取消尚未完成的穴位聚焦，修复跳回。缩放距离限制使用边界收敛，提供完整显示和回全身恢复。按住按钮连续缩放已实现，但可靠的持续按压时序与双指操作仍待实体设备验收。
4. 返回所选对象、展开观察 — 已修复并验证。看当前返回原穴位；进入、退出铺满看图同步拖动方式，底部不重复显示两套控制器。人体切换期间控制器暂时不可操作，避免旧人体操作写入新状态。
5. 穴名和手机详情 — 本轮自动扫描男性 670、女性 670 个左右侧显示记录，选择错配、非有限位置、选中穴名缺失均为 0。男性扫描窗口 390×844；女性扫描窗口 1280×872。后续详情复核发现新增底部控制器被误判为顶部遮挡，已改为按工具用途计算画面；短屏详情收起重复的经络切换栏，保留方向、缩放和详情，关闭详情恢复完整操作。最终在 390×844 和 320×568 打开少府 HT8 详情后定位复核：显示几何有限、点在线上间距 0、碰撞列表为空、当前皮肤接触点可见；关闭详情恢复完整控制。证据：26-phone-location-fixed.png、27-short-phone-fixed.png、short-detail-audit.json。
6. 男女及内部图层 — 本轮实际打开男性骨骼、神经（760结构）、胸腹内脏（303结构）、体表，控制器保留；女性体表与穴位局部观察可操作。修正女性直接链接先加载旧场景的路径，按链接所请求场景准备。证据：20-phone-nerves.png、21-phone-organs.png。最终男女往返与公开网页复核待追加。

## 验证范围及仍需继续处理

- 两次逐穴扫描是程序逐项选择、聚焦、名称检查，不是 1340 次真实手点，也不等于临床取穴校准。
- 本轮真实点击穴名、身体位置，鼠标拖动和 320×568、390×844 小屏检查；没有完成所有实体手机、辅助读屏、全部独立骨骼/内脏医学位置验收。
- 浏览器底层触控模拟长时间未响应，不能作为双指及长按验收证据；已恢复页面继续正常点击验证。
- 初次准备体表点线仍有明显等待，应继续优化加载、进度与中断反馈；本轮只减少女性链接中不需要的场景加载，不宣称加载性能问题全部解决。
- 骨骼在灰色背景上对比偏弱，后续应独立验证光照、骨色与图层透明度，避免通过修改医学结构掩盖问题。
- 361 标准代码、14 经脉名称/拼音、有限坐标、体表遮挡、绘线归属、血管筛选和皮肤接触点回归检查通过。临床校准仍为 0，旧模型来源和学习边界保留。
