# V27 观察与标注复盘

## 实际复现，而不是只看按钮状态

V26 在背面看经络时，顶部仍可能高亮“立体”，面板方向没有对应高亮；随后“看全线”又回到接近正面的方向。开启“仅看当前穴位附近”后再看全线，复选框还保持开启。390×700 的完整穴名模式里，前顶 GV21 的名称框与经络状态条重叠。

V27 首轮 Chromium 回归发现一个漏掉的女性分支：男性转向已保留局部距离，但女性 document 捕获阶段仍先调用旧的全身适配。右内关局部观察距离从约545变成6558模型单位。该路径已改成用户转向命令与男性共用；女性器官预设的程序化适配不受影响。首轮产物不作为发布依据。

## 本轮修复

1. 方向高亮来自相机真实朝向；自由拖动到斜角时，不继续声称正面或背面。顶部与经络面板保持同步。
2. 转向与取景范围分开：方向按钮保留当前观察中心和放大程度；“看全线”保留原来的朝向，并关闭显式局部裁切。
3. 完整穴名按真实可用空间排版分页，附近和完整名称框都避让控件及可见穴位中心。名称用中文左右侧，引线连接名称边界与落点。
4. OrbitControls 改变位置/朝向后，先更新相机矩阵再计算标注投影，避免渲染前沿用旧矩阵。检查在同一个 JavaScript 执行轮次中比较投影，不能等下一帧掩盖问题。
5. 皮肤画面、选点和界面没有变化时，复用标签布局，减少重复遮挡射线计算。没有用此计数宣称某个帧率提升比例。

## 验收方法

候选与公开网址分开保存结果。新脚本覆盖男女方向、局部缩放、完整穴名、翻页、静止画面复用、390×700短屏，以及390×844、2倍像素密度的模拟触控。另复跑V26的35项点位、绘线、男女切换、骨骼/胸腔及手机详情画面检查。最终通过数量以对应运行的报告和deployment-result.json为准。

## 保留的边界

本轮不是临床定位改版：不移动编号穴位，不改变原始经络几何、人体网格或女性模型来源。皮肤保持原不透明和深度遮挡策略，真实缺口不强行补线。密集全线总览的引线仍可能较长；肩颈、手足的个别几何转折及逐穴临床定位仍需复核。浏览器模拟触控与高像素密度不是实体手机、触控惯性或长期帧率验收。

V26保留回退。仅在两种浏览器的最终候选通过后发布V27，并在固定入口激活后另行核验公开网页。
