# V33 点线、名称与图层一致性复盘

本轮基于 V32。本地实际操作与截图检查使用 Codex 内置 Chromium 浏览器，覆盖桌面 1280×720、手机模拟 390×844 与短屏 337×640。没有将前轮 WebKit 检查计入本轮，也没有实体手机验收或逐穴临床校准。

## 验证证据

- 数据检查：361 唯一标准编码，14 经脉分别 11、20、45、21、9、19、67、27、9、23、44、14、28、24 条；名称/拼音跨目录与资料共源，参考坐标有限。
- 运行时显示检查：男女各 670 个锚点，未发现缺失皮肤接触、非有限几何、重复接触碰撞；点中心与所用线路节点的显示差值为 0。该指标只说明显示一致，不证明医学定位。
- 实际观察抽查：男女足三里 ST36、涌泉 KI1、大椎 GV14、百会 GV20，以及内关 PC6、中脘 CV12、女性乳中 ST17。观察了选中点、皮肤遮挡与穴名引线。不是对所有穴位的医学验收。
- 图层切换镜头检查：女性内关体表→神经保持相同镜头；男女切换按新皮肤接触位置转移观察中心。
- 受控几何检查：前后遮挡、隐藏前片显露后片、裁掉前片显露后片、隐藏目标片、透明皮肤深度遮挡、墨迹皮肤片归属实时更新。
- 最终构建与发布校验：应用及资料两个产物必须与本地审阅版本 SHA-256 完全一致；校验所有 91 个版本文件。V32 与 V31/V9/V11/V12 原始资源保持原样。
- 本地完整原始状态记录与截图保存在项目 analysis/ 下，便于下一轮复查。

## 仍需继续校准的准确性

现有定位登记 361 条中，190 条为模型标志估计，171 条为待复核；临床验证数为 0。原始坐标、本轮参照几何和医学状态均保留，没有通过视觉优化把条目标成已验证。女性显示包含原生模型与统一教学参照，仍需局部体表标志复核。

下一轮按胸腹、头颈、上下肢逐段复核路线转折、体表标志与骨度分寸，优先处理待复核条目，再检查男女局部差异。临床标准应结合 [WHO 标准穴位定位](https://iris.who.int/bitstream/handle/10665/353407/9789290613831-eng.pdf?sequence=1) 和专业人工复核；仅靠三维贴肤不能保证标准取穴位置。

## 本地运行

在仓库根目录启动 HTTP 静态服务，例如 `python3 -m http.server 8782 --bind 127.0.0.1`，打开 `http://127.0.0.1:8782/fullbody-tcm-v33/`。保留整个仓库资源；不要只复制 V33 文件夹。源码与本轮发布脚本均已留在仓库。
