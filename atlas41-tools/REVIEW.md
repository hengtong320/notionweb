# V41 · 身体负担观察、负荷适用性与对比

本轮从真实页面确认并修复两处分析问题：放松站立输入5 kg时，旧版会在原姿势中额外生成一个没有持握约束的箱子并显示4.3 N·m；经由相关姿势对比还会将这份质量延续到前臂靠柜台。另有腰背说明使用 slice(1)，丢掉第一条支撑与维持解释。

## 1. 流程健康：设定外物 → 看作用点 → 切换姿势

外物质量仅开放给已绑定可见物体与作用位置的19种姿势：箱子、提袋、背包、手机、吉他和游戏手柄。无适用外物的姿势禁用质量输入并清零；旧链接中的不适用质量也纠正。清扫工具接触地面、握把/方向盘由车辆支撑，尚无支撑分担和推拉阻力，因此不套用“整件工具重量由手承担”的假设。

删除“任意质量生成箱子”逻辑。外力矩使用画面外物的近似中心与模型腰部参照点，显示对应位置标记。设定质量不是模型实测；均匀物体、重力方向与近似中心是计算假设。台面、肩带及身体分担未求解，结果不是传入腰椎的真实力矩。

正常选姿势使用该项默认质量；相关姿势/场景对比仅在同一物体类型时保留设定质量。不同物体恢复当前项默认值，无适用外物清零并提示。外物重力矩的“不适用/未求解”和适用物体设定0 kg的“0 N·m”区别显示，不用0代替未知内部力。

## 2. 流程健康：腰背、颈肩、髋膝与支撑对比

恢复完整腰背首段。前臂台面支撑、靠背座面、床面左右承托、膝间枕、小腿支撑及桥式分别解释；保留每项具体动作说明。对比增加支撑的增减、三个部位说明、外物水平力臂和条件是否一致的解释。相同支撑名称也提示继续比较姿态与外物位置。

新增生活场景对照入口：放松站立、前臂支撑、靠背/无靠背坐、行走、近身/伸远箱子、左右侧卧、仰卧。两项质量或重力不同会明确指出条件变化，不能将数值差只归因于姿势。

实际7 kg近身箱子的水平力臂0.344 m，外物重力矩23.6 N·m；伸远箱子保持7 kg，力臂0.500 m、力矩34.4 N·m。这是当前模型和设定值，不能据此排名安全性或推断内部关节力。

## 3. 流程健康：持续状态与观察计划

区分静态保持、重复任务与姿势维持、活动总时长。行走/跑步/游泳等当前画面是动作阶段，不解释成固定这一帧30分钟。反复操作区分躯干维持和重复次数，未输入频率/力度便不估次数或疲劳。

计划给出转换的相对分钟、次数和最长连续任务段；不把终点算一次中途转换。间隔0表示没有安排中途转换。转换计划不等于实际执行或恢复程度，1/10/30/60分钟均不是医学疼痛阈值。

## 4. 验证与保留内容

- 实际浏览器逐项120姿势：210骨块有效、质量输入与适用性一致、无适用外物为0 kg且外力矩为null、腰背第一条解释均显示。
- 新增120姿势×5时长=600次分析检查，覆盖负荷拒绝、未知点、静态/活动/重复分类、转换边界、左右承托、三个部位对比、零重力与未知内力。
- 实际正反路径：旧负荷链接纠正、箱子7 kg近身↔伸远、箱子→站立、手机0.2 kg→阅读→手机、间隔0的60分钟、观察记录输出。
- 375×812手机实际对比，卡片单列，左右侧卧说明和无适用外物对比可读。
- 保留V40的120姿态、手指分节及腕部连接；原600个几何采样、23持物×5采样以及全手骨顶点穿入检查继续通过。
- 从未修改的V40通过补丁重建，108个根目录文件散列与审核版本一致。

## 公开依据与解释边界

姿势观察说明是模型支撑关系的教学解释；一般工作姿势/任务变化依据 [OSHA工作姿势](https://www.osha.gov/etools/computer-workstations/positions) 与 [OSHA工作过程](https://www.osha.gov/etools/computer-workstations/work-process)。久站与活动变化参考 [NIOSH久站综述](https://www.cdc.gov/niosh/bulletin/2014/standing.html)，搬物条件参考 [NIOSH搬运](https://www.cdc.gov/niosh/engcontrols/ecd/detail25.html)。卧躺支撑参考 [North Bristol NHS](https://www.nbt.nhs.uk/our-services/a-z-services/emergency-zone/ed-miu-patient-information/back-injuries) 的一般资料，未转为个体治疗建议。力矩仅使用重力与水平力臂的基本力学关系。

这些资料不支持本模型给出某个人的疼痛发生时间、恢复率、损伤概率或关节内力。肌肉/韧带/软组织、女性姿态配准、内脏变形、神经牵拉及经穴随姿态配准仍未实现；原静态解剖与男女经络入口保留。

## 复现

仓库根目录运行 `python3 atlas41-tools/prepare.py`，使用three@0.180.0、three-mesh-bvh@0.9.2、esbuild@0.25.10构建 `atlas41-tools/build.cjs`。以静态HTTP服务打开 `/fullbody-tcm-v41/pose.html`。本地 `?audit=1` 可显示检查结果，公开版不展示调试入口。
