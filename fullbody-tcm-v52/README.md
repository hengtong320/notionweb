# V52 握持贴合与局部观察

入口：[生活姿势](pose.html?v=52.0.0) · [解剖与经穴](index.html?v=52.0.0)

保留 120 种生活姿态、男女体表、经穴、骨架、器官、神经、血管与颈胸腰分节观察。

本轮修复胸前抱箱的肘部方向，使男女体表在既有交叉检测中都没有手臂穿胸。手机掌腕过渡进一步平滑，耳边接听也使用连续的八关节手部影响。手机外壳处修正不超过 2 毫米的浅层皮肤穿插，较深穿插不会被这项修正移开。修正后的表面同样用于穴位、线路、点选与显示遮挡；不是接触压力或材料力学求解。

“看手部接触”只聚焦实际持物的手，耳边接听不再把垂下的另一只手算入取景范围。缩放、旋转、平移和完整显示保留。

原始皮肤顶点、骨块、骨长和穴位坐标未改动。皮肤保持不透明。男女仍使用各自皮肤上的三角附着，女性其余共用结构仍是教学参考。

完整婴儿式的脚跟接触和深屈曲软组织贴合、直腿取物穿插、手指形态及逐穴定位校准仍未完成。真实内部受力、疲劳程度与病变预测未求解。
