# V54 左右腿随动与结构载入

入口：[生活姿势](pose.html?v=54.0.0) · [解剖与经穴](index.html?v=54.0.0)

保留 120 种生活姿态、男女体表、经络穴位、骨架、器官、神经、血管与颈胸腰分节观察。

左右腿按原体表连通区域绑定，避免内侧大腿同时跟随两腿。髋部保留连续过渡；男体腕部接缝的邻域与平滑过渡也已修正。盘腿分开双脚并把手放到对应膝上，交叠坐姿、侧坐、上楼及低处取物调整手臂摆放。原皮肤顶点、骨块、骨长和穴位坐标保留。

结构文件同时载入，绑定计算分段执行，并显示准备进度。点线仍附着于各自皮肤原三角形，使用与绘图相同的变形计算进行显示、选取和遮挡。男女切换保留观察和开关状态。

男性肩部接缝、深屈曲软组织贴合和部分手部任务仍未解决；坐着系鞋带的真实手指与足部接触也未完成。穴位未逐穴临床校准，女性共用关节比例仍是教学参考。内部受力与病变预测未求解。

检测口径、结果与待办见[本轮复核](../atlas54-tools/REVIEW.md)。
