# V58：头面部贴肤线路与男女不透明体表

本轮针对人体经络主页面的截图问题：男性嘴部线路断开、女性耳后断开，以及自定义骨骼＋体表组合中女性骨骼穿出皮肤。生活姿势几何沿用 V57，没有新增姿势试验。

## 实际修复

大肠经、小肠经和三焦经的头颈相邻穴位段，若原投影出现急转或离开皮肤，使用现有皮肤三角面的邻接路径修复。只接受贴肤且比原错误绕行更短的路径；保留编号穴位锚点、来源坐标和真实缺口，不跨空隙硬接，也不打开透视。原插值的平滑外观保留。

男女的完整不透明体表（不透明度至少 98%）显示时，保留已启用的内部结构状态，暂时收起其绘制。女性体表和补充骨骼来自不同教学参考，原来仅靠深度测试会露出穿出皮肤的骨头；本次修的是显示策略，没有伪称骨骼已完成女性临床配准。降低体表不透明度、关闭体表或单独查看结构时恢复内部结构；图层标明「已启用 · 体表遮挡」。局部隐藏、裁切、独立结构观察保留自己的显示逻辑。

## 验证范围

检查十四经脉在男女、左右侧和中线的全部 66 条现有分支，1358 次分支内锚点检查：锚点完全保留，没有新增断点；男性大肠经左右各 6 处断点及女性三焦经耳后左右各 1 处断点消除，总断点计数 48 降到 34。其他经脉的源网格缺口与未修复断点仍保留，不把它们宣布正常或已全部解决。真实网页图层、男女往返、透明恢复、穴名、点击和手机检查另见 atlas58-tools/REVIEW.md 与发布记录。

没有重新标定全部穴位，没有提供个体受力、疾病或损伤预测。连线仍为走向学习示意；完整内行与支脉、逐穴医学定位尚未完成。
