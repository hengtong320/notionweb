# V47 · 体表变形与观察操作修复

入口 `pose.html`，解剖页仍由 `index.html` 进入。保留120种不同生活动作和支撑条件、姿势图册、分段质心、重力、时间研究、条件对比和观察记录。

## 本轮修复

修正腕部转动中心偏移、女性上臂内侧区域误绑和局部掌部权重，减少举臂、前屈、侧卧时异常拉伸。皮肤权重在构建阶段生成并校验，穴线与可点击落点采用相同的皮肤变换。

方向按钮只改变方向，保留观察中心和距离；窗口变化不再退回全身，刷新恢复镜头。穴名尝试周围多个空位避让控件，用引线对应落点。加载图层时禁用定位和播放以避免作用到旧人体。

仍有手机握持拇指根部异常、婴儿式大腿/腹部相交、举臂腋部折叠等问题。[具体前后诊断与待办](../atlas47-tools/REVIEW.md)保留改善和退化数据，不声称全部姿势或经穴已正确。

## 继续保留的功能

- 姿势页可选男性或女性，查看骨架、体表经络、器官、神经和动静脉。女性体表、四块组合骨盆以及器官/血管采用现有 HRA 原生结构；其余骨架和全身神经使用明确标注来源的共用教学参考。没有把共用骨架声称为女性扫描。
- 男女各用自己的体表投影器。十四经脉、361个穴位编码及相应左右侧参考点接入原解剖页的定位数据和路线规则。点与线路绑定在各自体表三角面上，随关节链运动。皮肤保持不透明，背侧点正常遮挡；穴名只显示当前选中且可见的点。
- 线路、穴位、穴名、侧别和选中穴位在男女切换时保留。任督二脉使用中线。刷新恢复选中侧别、动作阶段、阶段文字和镜头。
- 内部结构支持中文/英文搜索、选择、定位、结构细分和突出所选；血管可筛选动脉或静脉。点击只命中当前可见结构。396个女性器官和血管目录条目具备中文显示名，来源字段仍保留。
- 女性分段质量和质心比例采用 de Leva 1996 表4女性参考参数。原表质量总和99.99%，保留原比例并归一化守恒输入体重。
- 在适用的静态、同地面足部支撑条件下，计算满足总垂直力与重力矩平衡的左右脚支撑力可能区间。实际分担未知；坐卧、多处支撑、运动和水中状态不套用这一求解。
- 保留明确的放大、缩小、旋转、平移和完整显示按钮。手机定位后回到三维画面；图册使用当前人体和结构视图，关闭后恢复姿势状态。

## 使用和研究边界

先选择生活姿势，再选人体和观察结构；体表视图选择经脉及穴位，内部视图搜索结构。改变体重、外物、重力和持续时间后，可生成、预览或下载 JSON 观察记录。

随动是连续权重的几何教学展示，未使用组织材料力学或个体临床配准。大幅弯曲、接触和源模型缺口区域仍可能压缩或相交；贴肤不代表医学取穴准确，原始经穴仍需逐点复核。腕部混合显示减少部分塌陷，没有软组织接触解算。阶段内播放仅用于行走、跑步和自由泳，其余运动提供独立关键状态；不是测量过的完整动作轨迹。

身体分段和外物的重力矩、参考重心、静态足部反力区间不能当成腰椎内力、肌肉力、椎间盘压力或足底压力实测。持续时间展示任务暴露和原研究条件，不预测个人疲劳、疼痛、恢复量或损伤概率。器官压力、神经张力和真实组织形变仍未求解。

## 本地运行及重建

在仓库根目录启动静态服务器，打开 `/fullbody-tcm-v47/pose.html`。例如 `python3 -m http.server 8783 --bind 127.0.0.1`。

重建固定依赖 three 0.180.0、three-mesh-bvh 0.9.2、esbuild 0.25.10；设置 NODE_PATH 后运行 `node atlas47-tools/build.cjs`。构建检查覆盖120姿势的600个关节状态、男女体表1200个状态、三角面附着、质量守恒、静态支撑边界和名称分类。它们是几何与程序检查，不是临床验收。
