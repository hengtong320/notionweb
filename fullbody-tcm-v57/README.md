# V57：屈髋屈膝握箱接触与体表修正

本轮在 V56 上继续修复第 49 项「搬箱 · 屈髋屈膝取物」。120 项生活姿势和男女、骨骼、皮肤经穴、器官、神经、血管功能仍保留。本轮没有把所有体表问题宣布解决。

## 实际修改

该姿势调整站距、箱子的相对位置和双臂的肘部方向；上臂和前臂按同一屈伸平面配准，腕部与手掌接触一起更新。骨长、腕关节连接、手指骨长及原始网格不改变。手掌接触点向箱面外微调，避免只看骨点吻合、皮肤却进入箱子。

女性该姿势叠加部分脊柱调整时，原绑定混入邻近手臂影响，腰部小范围会出现额外网格拉伸。新增仅针对该姿势的显示修正：原坐标高度 0.10–0.32 米的体表带和相邻面片边，单顶点位移上限 1.25 毫米。46 个男女及脊柱调整样例的最大实际位移约 0.465 毫米。修正后的表面法线同时更新；经络、穴位三角面附着、引线和皮肤点击采用相同位置。退出该姿势清空修正，重复相同姿态复用结果。计算时只继续处理已拉伸的边和被移动顶点的邻边，同时保持逐边处理顺序；减少重复扫描，不降低显示检查精度。另检查七轴端点的 128 种组合和 32 个确定性区间样例，包含男女共 320 个状态；极端组合的实际位移最高约 1.25 毫米。

这些是显示质量和近似接触修复。边长比例约束不是皮肤材料常数或损伤阈值，1.25 毫米不是医学定位精度；没有求组织压强、肌腱或肌肉力、病变椎节、个人疲劳或损伤概率。

七个脊柱调整的屏幕阅读名称与当前方向、角度一起更新，避免名称还报初始零值。

## 复核

先比较 46 个男女及单轴、前屈与侧弯组合状态的完整三角面穿插、边长变化、箱体实际三角网及刚性骨链约束，再逐点对照网页使用的显示内核与独立离线修正。实际 WebGL 检查增加到 134 个状态，每状态 2048 个位置样本；所有发生修正的法线顶点也经过独立绘制检查。结果见 atlas57-tools 的构建报告与 REVIEW.md，实际网页交互和发布状态另行留证。

完整体表回归仍检查 120 姿势 × 5 阶段 × 男女。检测排除共享顶点、源网已有相交及源面中心间距小于 40 毫米的局部面片，不能代替所有包含、接触及临床复核。浏览器视口和显卡检查不等于全部实体设备验收。

## 尚未完成

深屈膝的腿部和骨盆局部仍有穿插；男性抬臂肩部源分区接缝、女性抬臂局部翻折以及其他生活姿势的软组织质量仍需继续修复。此次握箱修复降低相交数量，不代表这一姿势已完全无穿插。经穴仍沿用学习参考数据，未逐穴完成医学定位校准。持续时间仍表达观察计划和研究条件，不会自动判定某节椎骨受损。
