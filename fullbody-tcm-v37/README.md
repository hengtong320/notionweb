# V37 姿势与受力观察

入口：`pose.html`。解剖页增加“姿势与受力”链接，原有男女、体表、经穴和内部结构操作保留。

同一男性参考骨架的 210 骨块，通过近似关节中心进行分段刚体摆位。包含站、坐、仰卧、静坐、跑步、游泳，以及瑜伽树式、战士式、下犬式。支持阶段选择、播放/暂停、旋转、平移、缩放和完整取景。

计算质量 × 重力；仅在静态平衡假设中显示总支撑。双脚比例为手动假设。水中按输入排水体积估算浮力。持续时间只展示设定时长和计划换姿次数，不推断疲劳、损伤、血流或组织变形。

观察记录先显示 JSON 预览，可复制或点击下载；输入变化会清除旧记录。参数保存在当前链接片段中，可重开复现。

这是研究预览：关节中心、角度、接触位置没有动作捕捉校准，没有肌肉/韧带/平衡求解。当前未实现女性姿势配准、器官和神经变形、穴位随姿势重定位、真实关节力或伤害预测。请勿把骨块摆位当成实际测量结果。

本地：在仓库根目录启动静态服务器，打开 `/fullbody-tcm-v37/pose.html`。重建需固定依赖 three 0.180.0、three-mesh-bvh 0.9.2、esbuild 0.25.10；设置 NODE_PATH 后运行 `node atlas37-tools/build.cjs`。所有旧版与原始模型资源保留。
