# V38 — 120种生活姿势与身体负担

用户指出V37姿势不自然、生活场景覆盖不足。本版重新建立120项有不同动作、侧别或支撑条件的目录，保留210块原始骨骼几何；新增手足目标约束、逐节腰椎和颈椎姿态、床椅枕垫及日常物品。主解剖页面保留原有男女、经络、器官与神经入口。

## 用户路径

1. 搜索或分类选择生活场景；图册使用实际骨架渲染预览。
2. 旋转、平移、缩放，或聚焦腰椎/颈肩/髋膝；完整显示恢复取景。
3. 看该姿势的支撑区域、身体维持需求和持续时间解释。
4. 展开条件修改质量、持物、重力等，比较相关姿势并导出观察记录。

覆盖卧躺16、坐姿16、站立12、搬抬12、家务12、出行运动12、工作12、休闲8、瑜伽12、游泳8。动作阶段包括跑步支撑/腾空、上下台阶、跳跃、左右划水等；只有已实现的行走/跑步支撑及擦地状态提供阶段播放，不将静态截面伪装成完整运动捕捉。

## 本地验证完成

- 自动检查120个独立关节配置、600个阶段样本；目标不可达误差超过3毫米为零；肢体、腰椎及颈椎链长度保留。
- 实际浏览器逐项选择120种姿势，确认210骨块变换有限、约束误差通过；两轮检查图册全部120项实际图像。
- 发现并修正盘坐悬空、侧卧手臂、交叠腿方向、跪姿脚部、下犬手掌、婴儿式和桥式、骑行脚部、电话/窗面/高架/水线错位等问题。
- 实际鼠标拖动旋转、平移和滚轮缩放通过。按钮缩放、完整取景、方向、聚焦、搜索、时间、输入校验、阶段/播放、对比、记录及图册退出已检查。
- 375×812和320×568浏览器视口检查；320宽的八个操作按钮均72×44像素，两排完整显示。该项不是所有实体手机验收。
- 原有经络361代码/14完整经脉、皮肤遮挡、贴肤落点、血管命名及异常状态检查通过。
- 重量、持物外力矩、零重力、浮力、换姿计划计算已验证。

## 解释边界

这是成人参考骨架的关节与支撑几何示意，不是人体有限元、肌肉骨骼动力学或临床诊断。支撑标记不是接触压力、重心或肌肉激活图。只计算给定持物相对于近似腰部参考点的重力外力矩；不计算椎间盘压力、肌肉力、疼痛/损伤概率或安全时长。水中仅计算给定排水体积的静态浮力，未计算推进和水阻。

姿势页使用原始男性成人参考骨架。女性体型姿势配准、器官/神经变形、经络/穴位随姿态贴附尚未实现，界面明确说明。主解剖的男女与器官等功能仍可从返回入口使用。关节中心与骨片刚体摆位不是逐人临床校准，软组织厚度及负荷平衡未求解。
