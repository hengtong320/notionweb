# V53 自然站姿与坐姿手部

入口：[生活姿势](pose.html?v=53.0.0) · [解剖与经穴](index.html?v=53.0.0)

保留 120 种生活姿态、男女体表、经穴、骨架、器官、神经、血管与颈胸腰分节观察。

放松手臂采用稍向外的间距；直坐、后靠和弓背的放腿手部目标分别调整。原始皮肤顶点、骨块、骨长和穴位坐标保留。这些是参考姿态的几何调整，尚未计算掌部接触压力和软组织压缩。

保留 V52 的手机浅层接触、胸前抱箱、实际持物手取景和相机控制。穴位与线条继续附着于各自皮肤的原三角形，使用同一变形计算参与显示、选取和遮挡。

男性肩部接缝的绑定问题正在继续修正，尚未通过举臂与游泳回归，实验方案没有纳入此版本。完整婴儿式、盘腿、跷腿的软组织贴合、部分持物穿插及逐穴临床定位也未完成。真实内部受力、疲劳程度与病变预测未求解，女性共用结构仍是教学比例参考。

检测口径、结果与待办见[本轮复核](../atlas53-tools/REVIEW.md)。
