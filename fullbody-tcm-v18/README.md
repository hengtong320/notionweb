# V18.0.0 统一身材比例与逐穴模型约束

## 本次实际完成

男女采用相同的教学身高、四肢长度参照及横向比例。女性仍使用自己的皮肤与内部器官网格，按同一连续变换归一化，不换成男性器官；乳腺、子宫等特有结构保留。髋部外形与大腿连续过渡，手臂适配范围不再误影响大腿。原始 GLB 文件不改写。统一比例是教学显示，不是临床器官配准，也不声称实际男女解剖形态相同。

361 个标准穴名均有独立的定位来源、书页索引、原位置、显示规则和复核状态。190 个穴名增加模型标志或骨度分寸约束；171 个仍保留原参照，细定位待复核。没有任何穴位被标为临床配准通过。甲角点的微小 F-cun 间距、体位相关点以及不能在当前网格辨认的软组织标志仍需专门审核。

不再用几条固定前臂通道均匀排点。腕、肘、脐、胫骨、肋骨、棘突和甲角等可识别模型标志用于约束相应点位。女性 ST17 另按女性乳头模型确定显示参照，不复用男性乳头高度。

33 条体表路线分支逐个通过所包含的穴位中心，而非将点拖向一条先画好的漂亮曲线。曲线沿当前皮肤重新采样，避开穿空连接；正常深度模式保持身体遮挡。中心实点表示图形落点，外圈只扩大点选范围，不代表穴位面积。口内的龈交等点位不能被本外表模型确认为准确。
