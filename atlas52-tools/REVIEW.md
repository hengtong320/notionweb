# V52 握持贴合与局部观察复核

基线为已发布 V51。保留 120 项生活场景、不透明体表、男女各自皮肤附着、所有解剖层与相机控制。原始皮肤顶点、骨块、骨长、穴位坐标及绑定缓存未移动或替换。

## 本轮修复

- 胸前抱箱采用向外的肘部方向参照，手部接触目标和骨长不变。原男性手臂穿胸 886 对新皮肤三角交叉降至 0，女性保持 0。
- 手机掌腕混合从 0.4 调为 0.6，沿原掌轴渐变；指骨仍按原握持骨链运动。耳边接听也使用已有八关节连续手部影响，降低相邻手指权重跳变。
- 手机外壳处只修正位移不超过 2 毫米的浅层显示接触，外壳间隙 0.05 毫米。源顶点不改动；修正施加在随姿势生成的表面上。深穿插不会被本步骤移开。CPU 三角附着、点选、遮挡与 GPU 位置/法线使用同一修正。此步骤不是组织压缩、接触反力或材料力学求解；手机圆角和三角面内插仍需更精细的接触验证。
- “看手部接触”只把实际持物的手纳入取景。耳边接听不再因未持物左手垂下而退到远景；双手抱箱仍看双手。
