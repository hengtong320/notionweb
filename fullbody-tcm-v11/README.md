# V11 器官、血管与体表参照

保留原界面、模型、拆解、资料与当前对象联动，新增胸腔、心脏、腹部、心血管和左右耳观察入口。
新增结构按需从本站加载。名称来自固定版本源词典，少数未翻译结构保留原文；形状与原始全局变换保留，统一使用前版坐标框架。
体表为同源区域表面拼合，不是皮肤组织分层、皮下脂肪或临床扫描。贴面功能是独立的显示投影，原穴位数据不改；其线路和点仍未临床校准，不能用于准确取穴。
胸腹模型是现有源数据的可用结构，不宣称全部器官、毛细血管和神经末梢已齐全。耳部保留外耳细分及源模型中的部分内部结构，不是完整显微解剖。
红蓝血管颜色表示动静脉分类，不等同于血氧含量。点击结构可聚焦、单独看或隐藏。
证据与源坐标信息见 assets/new-source-manifest.json、assets/new-catalog.json 以及 checks/。旧版与共享v9资源保持不变。
