# V47 体表变形与观察操作修复

2026-10-05，基于已发布 V46。保留全部 120 种姿势、361 个穴位编码、十四经脉及男女五种观察结构。V46 和原始模型资产不改动。

## 本轮实际修正

1. 原腕部参照点与源舟骨/月骨中心相距约 46 mm，非握持姿势和握持姿势曾使用不同的腕部基准。统一到源腕骨中心；骨块仍作刚体变换，未缩放任何原骨网格。参照肘腕链长度因此重新计算，并微调四点支撑的目标高度和后撑坐姿另一手的可达目标；不是维持错误的旧参照长度。
2. 女性源体表的一些上臂内侧点被粗略坐标区域误判为躯干。沿原生网格连通区域识别两臂，在肩部过渡到身体区域，并平滑过陡的影响权重。男性保留原分区标签，避免把女性权重处理直接套用而造成男性腋部退化。
3. 掌部权重沿已有表面边连续混合；非握持的前臂/腕部皮肤使用部分双四元数旋转混合以减少塌陷。握持时保留线性混合，因为目前试验中旋转混合会增加拇指连接异常。点线与实际皮肤共用变换和三角面重心坐标；纠正过渡实现中 CPU 与 GPU 旋转混合不一致的问题。保持皮肤不透明。
4. 在构建时生成男女皮肤权重缓存，网页加载时校验源位置、关节调色板和缓存摘要；避免每次切换人体都在界面线程执行权重求解。两份缓存共约 6.4 MB，原始体表顶点和面未移动或替换。
5. 姿势页正面、侧面、俯视按钮现在只改变方向，保持观察中心和距离。窗口尺寸变化更新投影而不退回全身。保存地址包括镜头和目标，初始状态恢复完成后再写入；刷新可以继续原来的局部观察。完整显示仍负责重新取景。
6. 选中穴名在点周围尝试八个位置，避让控件与支撑标注，并用引线连接落点；空间不足或点被皮肤遮挡时仍隐藏画面穴名，选择框和说明保留对应名称。男女/图层加载期间暂时禁用定位和播放，避免操作使用旧人体。

## 必要回归与实际画面

构建复查 361 编码和十四经脉、600 个骨架状态的关节链与可达目标、握持骨块接触和指链、观察条件/时间/未知力字段、600 个分段质量与重力状态、静态足部支撑区间、396 个女性原生结构的中文目录。

男女原体表共 266990 个源顶点权重归一化与静止恒等均通过。120 姿势 × 5 阶段 × 2 人体共 1200 个状态检查采样顶点/面有限性及三角附着一致性；本次采样最大边比约 6.46。采样通过不代表所有面都无变形。48 组完整边诊断和 144 组区域相交诊断另行输出，包含残留异常；原来灾难性断裂筛查容差没有放宽。新增回归约束包括关键女性举臂/前屈场景最大异常边比至少减半、各对照场景超过 3 倍边计数不增加、侧卧蜷腿相交计数下降及男性腋部不退化。

本地实际浏览器证据在项目 analysis/v47-validation，保存男性后撑坐姿和女性下犬式同姿势、同阶段、同镜头的前后图与镜头数值。另完成 针对性操作检查，覆盖镜头保持、刷新、手机播放与男女切换、开关、穴名、实际画面点选、结构图层及定位；男女十四经脉在后撑坐姿检查 1340 个双侧/中线点实例的有限性与原三角绑定一致性，并逐经脉实际定位。它不是每一个穴位都经过人工临床核验。数值诊断 JSON 以 8 位小数记录浮点值，避免运行环境最后几位差异导致摘要不稳定；计算、筛查条件和通过阈值没有变动，皮肤二进制权重缓存保持原 Float32 精度。只报告本轮实际操作，不复用 V46 操作数量冒充 V47 全按钮验收。发布时核对全部版本文件摘要，并在公开页复查实际加载和点选。

## 仍需继续解决的具体问题

- 女性下犬式和蛙泳伸臂的腋部过渡仍有明显折叠/压缩；固定关节链与蒙皮不是肌肉和皮下组织模型。
- 看手机时拇指根部和掌部仍有异常拉伸，男性两手相交计数略增加，女性有所减少但未消除；需要分别复核源手型配准、指链转轴、握持目标与皮肤影响区域。
- 婴儿式的大腿/腹部、胸前抱箱的手臂/躯干接触仍有新相交，部分计数增加。未增加软组织接触约束，不能当作真实受压形状。
- 源体表缺口保持原样。所有经穴没有逐点临床校准；三角附着一致证明点随皮肤，不能证明取穴位置正确。
- 尚无个体女性完整关节链、器官材料变形、神经张力、肌肉激活、内部关节力、椎间盘压力或个人时间疲劳预测。现有重力/静态支撑与研究说明继续保留，但不把几何改进称为这些真实求解已完成。

本轮是具体缺陷修复版本，整个研究目标仍需继续迭代。
