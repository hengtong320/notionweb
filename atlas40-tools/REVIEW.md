# V40 · 持物姿势精修与复核

本轮在 V39 的 120 种生活姿势之上，修复持物时手骨整块转动、手掌与物体没有接触、腕部旋转后出现间隙，以及手机手部取景裁切。保留经络男女切换与加载状态修复。

## 1. 流程健康：选择姿势 → 看完整身体 → 放大接触 → 看分析

- 120 项实际浏览器逐项点选：选中姿势正确、210 骨块有效、无无效变换；23 个持物姿势的手部观察入口显示，其余隐藏。
- 正面、侧面、完整显示、放大、缩小、旋转和平移入口可用；放大后相机距离按 0.8 缩放，缩小恢复原距离。
- 新增“看手部接触”，隐藏特写内的支撑标签和重力箭头；恢复全身时恢复这些提示。
- 320×568、375×812 手机视口实测：按当前镜头方向和标题/操作栏间的可用空间取景；修复三行工具栏与加入对比条重叠。属于浏览器视口复核，非实体手机验收。

## 2. 流程健康：持物接触

- 从原骨模型推得近似腕部中心；持物上肢使用这一中心保持前臂和手部的共同旋转节点，不再以远离腕骨的旧参照点旋转。
- 每根手指按指节分别变换，保留原骨几何与关节链长度。拇指和其余四指分别设置目标。
- 095 吉他：右手置于弦面，左手指向琴颈，拇指在琴颈后方；琴弦贴近琴颈表面。096 手柄：掌心朝向握把，四指绕前缘，拇指朝向顶面按钮。
- 手机、电话到耳、方向盘、提袋、搬箱、扫地、拖把、吸尘和自行车握把分别定义接触方向；箱子与清扫工具在手臂可达范围内共同调整物体与手，不拉长骨块。
- 23 个持物姿势全部实点并保存接触画面；095/096 另外保存正侧面全身与特写。

## 3. 构建及几何验证

- 120 个不同关节配置、600 个姿态采样，原身体支撑目标可达，肢体及脊柱链长度保持。
- 23 持物姿势 × 5 采样 = 115 次接触检查：掌心/明确指尖目标误差 ≤3 mm，腕部共同节点一致，手指链及上肢长度保持，全部骨块变换有效。静态姿势的采样不代表五个不同动作。
- 对原手骨每个顶点与持物几何做穿入检查：最大近似穿入 1.433 mm，接受阈值 2 mm。这个容差针对骨网格与简化物体形状；没有声称零穿透、真实软组织接触或全身碰撞求解。
- 经络、名称、遮挡、皮肤落点与血管数据检查通过；未重做临床穴位定位。
- 从未修改的 V39 通过发布补丁重建，107 个根目录文件散列与本地审核版本一致。

## 4. 明确边界

这是生活姿势与支撑关系的学习示意：关节中心从模型估计，指骨为刚体铰链。尚无肌腱/肌肉/软组织、个体测量、动态地面反力、真实内脏变形和关节内力求解。因此不能预测某姿势持续多久必然疼痛、损伤概率或个人诊断；页面保留这些未知量的说明。

## 复现

在仓库根目录运行 `python3 atlas40-tools/prepare.py`，以 three@0.180.0、three-mesh-bvh@0.9.2、esbuild@0.25.10 构建 `atlas40-tools/build.cjs`。构建包含数据、120 姿态与持物几何检查。用任意静态 HTTP 服务启动仓库，打开 `/fullbody-tcm-v40/pose.html`；本地 `?audit=1` 可显示检查结果。

本轮源骨模型、男女皮肤资产及原临床参考数据未改。固定入口由发布流程更新至 V40。
