# V49 · 姿势中的分层与脊柱分节观察

本地使用仓库根目录作为静态服务目录，打开 `fullbody-tcm-v49/pose.html`。固定入口为 `anatomy/`。

保留 120 种生活姿势，男女可切换骨架、皮肤与经穴、内脏、神经、动静脉。点击腰椎、颈肩、髋膝只调整镜头，保留当前图层。握持与遮挡修复继承 V48。

新增 T1–T12 独立教学关节链，七项附加设置覆盖颈腰前后屈与侧屈、胸段前后屈与侧屈及转向。24 个骨块可逐节定位，观察相对同姿势零附加设置时的中心位移与方向差。皮肤、经穴与内部结构按同一姿势随动；附加设置、选择节段、镜头和图层可保存到链接或观察记录。

肋骨按编号胸椎作刚体随动，肩带随 T2，胸骨随 T6；未求解肋软骨和肋椎关节运动。零胸段调整保留 V48 姿势和体表缓存。源骨块大小、源皮肤位置和拓扑不变，女性原生体表、骨盆及器官保留。

这是参考几何与外部重力项的学习工具。未测椎体终板，不能给出临床 Cobb 角、病变节段、腰椎压力、神经张力或损伤概率。时长显示任务暴露和研究依据，不会自动把某节骨头变成受损。仍有原始皮肤缺口、握持局部褶皱与穿插、未校准穴位和真实材料求解待处理。
